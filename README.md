# Udaaan Primary School Website (Edukids)

A premium, high-converting educational website for Udaaan Primary School.

## 🚀 Features
- **Modern Design**: Built with a deep navy and vibrant coral aesthetic.
- **Localized Content**: Optimized for the Indian education context.
- **Responsive**: Mobile-friendly navigation and layouts.
- **Multi-page**: Sections for Home, About, Admissions, Activities, Gallery, Blog, and Contact.

## 📦 Deployment
This project is pre-configured for **Vercel** hosting. 
Simply push to GitHub and connect the repository in the Vercel dashboard.

## 🛠️ Tech Stack
- HTML5 / CSS3 / Vanilla JS
- Font Awesome 6
- Google Fonts (Outfit, Inter)
